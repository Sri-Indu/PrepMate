# Sample / demo data

All files in this folder are **synthetic demo data**. They are not a real person’s resume or a real job posting.

Judges and local testers can use this material so they do not need to upload a private PDF.

Do not mix this data with real user sessions in the UI. Label it clearly as demo.

Files:

- `resume.txt` — fictional Alex Rivera resume (plain text)
- `demo_resume.pdf` — same resume as a PDF for `POST /analysis` and PDF extraction
- `job_description.txt` — fictional Software Engineer JD (Spring Boot, PostgreSQL, Docker, Kafka, AWS)
- `DEMO_CANDIDATE.md` — short profile card
